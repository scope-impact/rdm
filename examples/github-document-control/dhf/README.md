# Design History File

This directory is this product's DHF. RDM holds it to the product's spec
(`../.pi/`: requirements as stamped scenarios, user needs as Allium
surfaces), with the design documents (`documents/design/`), executed test
results (Allure) and git history — approval is the reviewed, merged commit.

Every change follows the same loop: spec → tagged acceptance test → gates →
generated traceability matrix → independently reviewed pull request.

Gate and verify exactly as CI does:

```bash
pytest tests/acceptance --clean-alluredir --alluredir=dhf/allure-results
rdm story verify --dhf dhf --allure-results dhf/allure-results -o dhf/data/verification.yml
rdm story release-gate --dhf dhf --allure-results dhf/allure-results
```

`dhf/allure-results/` and `dhf/data/verification.yml` are generated by running
the suite — gitignore them; they are never committed. `dhf/data/history.yml`
and `dhf/data/dmr.yml` are controlled data the documents render from, and are.
