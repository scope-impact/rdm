# Domain wiki

The domain, distilled from the raw sources (`dhf/raw/`). The wiki sits
between the sources and the spec: a user need or a scenario restates what a
wiki page says, and a wiki page restates what a source says.

## Rules

- **Every claim footnotes the source it came from**, as
  `<source>:<path>@<commit>` with the section.
- **Where a page and a source disagree, the source wins** and the page is the
  bug.
- **No page names an implementation**: the configured stack words are
  refused.
- **Every page is listed below**, and nothing is listed that is not a page.
