# Decisions

Each decision that shapes the spec is recorded here, one file per decision:
`adr-NNNN-<title>.md`, numbered in order and never renumbered.

- **Each record says** its status, the context that called for the decision,
  the decision itself and its consequences.
- **A decision is changed by a new record** that supersedes it, never by
  rewriting the old one; the old record says which one superseded it.
- **Where the spec is silent**, the decision that settles it is recorded here
  and written into the spec by the next spec change.
