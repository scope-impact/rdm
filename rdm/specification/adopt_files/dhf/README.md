# Design History File

This directory is this product's DHF as RDM reads it: the controlled
documents, the risk register, executed test results (Allure) and git
history; approval is the reviewed, merged commit. The requirements and user
needs are not here: RDM reads them from the product's Gherkin spec (see
`spec` in `config.yml`).

Verify and gate exactly as CI does:

```bash
pytest tests/acceptance --clean-alluredir --alluredir=dhf/allure-results
rdm story verify --dhf dhf --allure-results dhf/allure-results -o dhf/data/verification.yml
rdm story release-gate --dhf dhf --allure-results dhf/allure-results
rdm gap <checklist> dhf/documents/*.md
```

`dhf/allure-results/` and `dhf/data/` are generated by running the suite —
gitignore them; they are never committed.
