## Question

`TRACE.follow_latest` distinguishes "this test verifies requirement v3" from "this test verifies the current requirement", and the model argues regulated traceability needs both.

Markdown-first has no way to say either today: `satisfies: [UN-001]` points at whatever UN-001 currently says, so every trace in the estate is implicitly `follow_latest = true`. Kiwi TCMS solves the executed-test half with `case_text_version`.

Decide how a markdown source expresses a revision-pinned trace — and whether it needs to at all before the first design freeze. Depends on how revisions are represented.
