## Question

`SNAPSHOT`/`SNAPSHOT_ENTRY` pin a set of revisions under a label. Nothing in the estate produces one: halla-health-infra has zero git tags, and no release process emits a freeze.

For a regulated DHF the snapshot is the design-freeze record, so this is the core-model table with the largest gap between the model and current practice. Decide what a snapshot pins (every item, or the DHF deliverables only), how it is taken (git tag, an rdm command, a CI step on release), and what it guarantees about reproducing the frozen document set. Depends on how revisions are represented.
