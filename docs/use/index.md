# Operating instructions

Each change to a product runs through the same loop. The pages of this
chapter follow it.

```
 write the record ──► tag the tests ──► run the gates ──► review and merge
   (record)            (record)          (gates)            (your forge)
        ▲                                                       │
        └──────── query the graph, render the documents ◄───────┘
```

| Task | Page |
|---|---|
| Make a change the record-first way, step by step | [Changing the record](changing-the-record.md) |
| Declare user needs and design inputs, write and tag the tests | [Design inputs and tests](design-inputs-and-tests.md) |
| Keep the risk register and its controls | [Risk register](risk-register.md) |
| Record formative usability evidence | [Validation evidence](validation-evidence.md) |
| Run the design gate and the release gate | [The gates](gates.md) |
| Check documents against a standard's checklist | [Gap analysis](gap-analysis.md) |
| Run the gates in CI | [The gates in your CI](ci.md) |
| Query the record as a graph | [The record as a graph](graph.md) |
| Browse the graph | [Browsing in Graph Explorer](graph-explorer.md) |
| Let agents read the record | [For agents](agents.md) |
| Render documents and keep the C4 diagrams | [Authoring and rendering](documents.md) |

When a step fails, see [Troubleshooting](../troubleshooting.md).
